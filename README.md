# Rajat Singh Portfolio

A responsive, light-theme personal landing page for Rajat Singh, founder of Growth Karo. The site introduces two audiences: brands seeking digital growth and political leaders seeking digital PR, with a colorful Three.js hero, scroll-triggered animations, and mobile-first layout refinements.

## Project rules

Before modifying this project, read `PROJECT.md` and the current `index.html`.

## Files

- `index.html` contains the full page, responsive styles, inline SVG artwork, navigation behavior, Three.js-powered colorful 3D hero, founder portrait, scroll-reveal transitions, and floating/hover motion.
- `assets/rajat-singh-photo.webp` is an optimized version of the original portrait used in the hero and About section.
- `PROJECT.md` records the current product brief, audience, brand decisions, visual direction, sources, and implementation notes.

## Run locally

Open `index.html` in a modern browser. The 3D hero imports Three.js from jsDelivr, so it needs an internet connection. If WebGL or the CDN is unavailable, the CSS orb fallback remains visible. No build step is required.

## Contact and content

- Brand and political PR inquiries open WhatsApp using Growth Karo's published contact link.
- Case names and reported figures are drawn from [Growth Karo's portfolio](https://growthkaro.in/portfolio). The figures are identified in the page as reported site metrics and should be verified before use in paid promotion.
- Portrait: an optimized WebP made from the original photo supplied for this website, stored at `assets/rajat-singh-photo.webp` and shown in rounded, animated frames in the hero and About section.
- Instagram: [@rajatsingh_boss2](https://www.instagram.com/rajatsingh_boss2/).
